# Sunset Drive — OutRun風レトロレース

ブラウザでそのまま遊べる、OutRun風の疑似3Dドライビングゲームです。  
のんびり走行を想定した低速設定で、周囲の交通は車1台・バイク1台のみです。

## 遊び方

1. `index.html` をブラウザで開く
2. 操作:
   - **↑ / W** — 加速
   - **↓ / S** — 減速
   - **← → / A D** — ハンドル
   - **Space** — ブレーキ

## 特徴

- 疑似3D道路（セグメント方式）
- ヤシの木・観客・海沿いの風景
- 赤いオープンカー（後方視点）
- スピードメーター・タイム・ステージ表示などレトロHUD

## ローカルサーバー（任意）

```bash
cd outrun
python3 -m http.server 8080
# http://localhost:8080 を開く
```
