# 引き継ぎメモ — 大戦略風 六角ターン制ストラテジー

新エージェント / 開発者向けの引き継ぎドキュメントです。  
**最終更新**: 2026-06-10

---

## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| 名称 | Daisenryaku Proto（大戦略プロトタイプ） |
| 参考ゲーム | スーパー大戦略98（PC-98風レトロ戦略） |
| リポジトリ | `tarosiba/kakeibo` |
| 作業ブランチ | `cursor/godot-hex-prototype-17bd` |
| Pull Request | [#9](https://github.com/tarosiba/kakeibo/pull/9) |
| プロジェクトパス | `daisenryaku_proto/` |
| 起動シーン | `scenes/boot.tscn` |

個人・小規模向けに段階的に機能を追加してきた Godot 4 プロトタイプ。  
大戦略の「六角マップ + ターン制 + 軍事ユニット + 拠点経済」を最小〜中規模で再現している。

---

## 2. 技術スタック

- **エンジン**: Godot 4.3
- **言語**: GDScript
- **座標系**: Axial 座標 (q, r)、Pointy-top 六角
- **描画**: ランタイム生成ピクセルアート（`TileAtlas`）
- **データ形式**: JSON（マップ・セーブ）
- **Autoload**: `GameSession`（マップ選択・ロード状態管理）

---

## 3. 起動方法

```bash
# Godot 4.x をインストール後
# daisenryaku_proto/project.godot を開いて F5
```

ブートメニューから選択:

| メニュー | 内容 |
|---|---|

## 6. ゲームルール（仕様）

### 移動・攻撃

- 1ユニット / ターン: **移動 OR 攻撃**（どちらか1回）
- 行動後ユニットは灰色表示（`has_acted = true`）
- 未行動ユニットが残っていても「ターン終了」で敵ターンへ進める

### 戦闘

```
ダメージ = max(1, 攻撃力 - 防御力 - 地形防御)
```

| 地形 | 移動コスト | 防御補正 |
|---|---|---|
| 平原 | 1 | 0 |
| 森林 | 2 | +1 |
| 海 | 不可 | 0 |
| 山 | 不可 | +2 |

- **反撃**: 防御側が生存かつ射程内なら自動反撃（ターン消費なし）

### 経済・生産

- ターン開始時に自軍拠点から収入
- 拠点クリックで生産メニュー
- **1基地 / 1ターン / 1生産**（基地マスが空いていること）
- 初期資金: $800（自軍・敵とも）

### 生産可能ユニット

| ユニット | コスト | 移動 | 射程 | 攻撃 | 防御 | HP |
|---|---|---|---|---|---|---|
| 歩兵 | $300 | 3 | 1 | 3 | 1 | 8 |
| 戦車 | $600 | 4 | 1 | 5 | 2 | 12 |
| 砲兵 | $500 | 2 | 2 | 4 | 0 | 6 |

### 勝敗

- **勝利**: 敵ユニット全滅 **かつ** 敵基地をすべて占領
- **敗北**: 自軍ユニット全滅 **かつ** 自軍基地をすべて喪失
- ユニット全滅でも基地と資金が残れば生産で復活可能

## 7. 操作一覧

### ゲーム中

| 操作 | 動作 |
|---|---|
| 左クリック（自軍ユニット） | 選択 |
| 左クリック（青マス） | 移動 |
| 左クリック（赤マス） | 攻撃 |
| 左クリック（自軍基地） | 生産メニュー |
| Tab / 次のユニット | ユニット切替 |
| 右クリック | 選択解除 |
| S1〜S3 | スロットへセーブ |
| L1〜L3 | スロットからロード |
| ターン終了 | 敵ターンへ |
| メニューへ | ブート画面に戻る |

### マップエディタ

| 操作 | 動作 |
|---|---|
| 左クリック | 選択ツールで配置 |
| 右クリック | 地形を平原に戻し、拠点・ユニット削除 |
| map_01 読込 | デフォルトマップを読み込み |
| 保存 | `user://maps/custom_map.json` |
| テストプレイ | その場でゲーム開始 |

## 9. データ保存先

| 種類 | パス | 用途 |
|---|---|---|
| マップ編集 | `user://maps/custom_map.json` | エディタで作成したマップ |
| マップ同梱 | `res://data/maps/custom_map.json` | リポジトリ同梱サンプル |
| 進行セーブ | `user://saves/slot_1.json` | スロット1 |
| 進行セーブ | `user://saves/slot_2.json` | スロット2 |
| 進行セーブ | `user://saves/slot_3.json` | スロット3 |

- 旧 `game_save.json` は起動時に **スロット1へ自動移行**
- マップ保存と進行セーブは **別システム**（混同注意）

## 10. 主要クラス・シグナル

### HexMap (`hex_map.gd`)

- `setup_map(map_data)` — マップ全体構築
- `get_reachable()` — BFS 移動範囲
- `get_attack_targets()` — 攻撃可能マス
- `attack_unit()` — 攻撃 + 反撃解決
- `produce_unit()` — 拠点生産
- `capture_runtime_state()` / `restore_runtime_state()` — セーブ用

### GameManager (`game_manager.gd`)

- 状態: `IDLE` / `UNIT_SELECTED` / `BASE_SELECTED`
- ターン: `PLAYER` / `ENEMY`
- 勝敗: `NONE` / `VICTORY` / `DEFEAT`

### GameSession (Autoload)

- `set_default_map()` / `set_custom_map()` / `set_editor_test_map()`
- `set_resume_from_save()` — スロットロード時

## 11. 拡張ガイド

### 新ユニット追加（例: 自走砲）

1. `scripts/unit.gd` — `UnitType` enum に追加、`_draw_xxx()` 実装
2. `scripts/unit_catalog.gd` — ステータス・価格を追加
3. `data/map_01.gd` — 初期配置（任意）
4. `scripts/map_editor.gd` — エディタツール追加（任意）

### 特殊移動（例: 攻撃ヘリ）

- `hex_map.gd` の `get_reachable()` で地形コストをユニット別に分岐
- `terrain.gd` に「航空ユニットは海・山を通過可」などのルール追加

### ピクセルアート差し替え

- `tile_atlas.gd` の生成ロジックを `res://assets/tiles/*.png` 読み込みに変更

### マップ追加

- `data/map_01.gd` を参考に新マップ定義を作成
- またはマップエディタで作成 → JSON 保存

---

## 12. 既知の制約・注意点

- セーブは **プレイヤーターン中のみ**（敵ターン・勝敗確定後は不可）
- ロードはプレイヤーターン中に可能（L1〜L3）
- 敵ターンは `await` を使うため、デバッグ時に中断に注意
- `hex_map._ready()` は `GameSession.has_resume_save()` 時は自動セットアップをスキップ（`GameManager` が復元担当）
- マップエディタの「テストプレイ」は `GameSession.set_editor_test_map()` 経由
