# 現代国家シミュレーター

ヴィクトリア3風の、シンプルな現代国家運営ブラウザゲームです。元首として内政・経済・貿易・外交を四半期ターンで進めます。

## 遊び方

1. ブラウザで `index.html` を開く（または下記のローカルサーバー）
2. プレイする国家を選択
3. 税率の調整、投資、貿易協定、外交を行い「次の四半期へ」でターン進行
4. 20ターン（5年）耐えるか、財政破綻・政変を避ける
5. **世界地図**で各国の位置・外交関係・貿易ルートを確認（国をクリック）
6. **セーブ**ボタンまたは自動セーブで進行を保存（手動3スロット + 自動セーブ）

## ローカルで起動

```bash
cd /workspace
python3 -m http.server 8080
```

ブラウザで http://localhost:8080 を開いてください。

## ゲーム要素（簡素版）

| 要素 | 内容 |
|------|------|
| 内政 | 税率、産業・福祉・インフラ投資 |
| 経済 | GDP成長、税収、国庫、輸出収入 |
| 貿易 | 他国との貿易協定（関係30以上） |
| 外交 | 関係改善、制裁 |
| 世界地図 | 各大陸シルエット・経緯グリッド・海洋名（Vic3風）、国名表示、貿易ルート、クリックで詳細 |
| セーブ | localStorage（スロット1〜3 + 自動セーブ） |
| 勝敗 | 国庫・安定度で敗北、20ターンでスコア評価 |
