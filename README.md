# Fairway Chronicle（フェアウェイ・クロニクル）

ビッグオナー風レトロゴルフの **Godot 4 最小プロトタイプ** です。  
1ホール（No.17 / 663Y / par 5）を、マルチパネルUIでプレイできます。

> 本作は「ビッグオナー」「人生ゲーム」の名称・キャラ・デザインを流用していません。雰囲気と操作感のみを参考にしたオリジナル作品です。

## 含まれる機能

- **マルチウィンドウUI** — コースマップ / メインビュー / 標高グラフ / 操作パネル / ステータスバー
- **クラブ選択** — 1W, 3W, 5I, 7I, PW, SW, PT
- **方向調整** — 左右キーまたはパネルの矢印
- **パワーゲージ** — SHOT後にゲージが往復、Space/Enterで確定
- **風・ライ・距離** — 向かい風5m、フェアウェイ/ラフ/バンカー/池/グリーン
- **レトロ風描画** — 低解像度フィルタ、PC-98風パネルUI

## 必要環境

- [Godot 4.4+](https://godotengine.org/download)

## 起動方法

1. Godotエディタでこのフォルダを開く
2. `scenes/main.tscn` がメインシーンとして登録済み
3. F5（実行）でプレイ

コマンドライン:

```bash
godot --path . res://scenes/main.tscn
```

## 操作

| 操作 | キー / UI |
|------|-----------|
| クラブ変更 | ↑↓ または右パネル `<` `>` |
| 方向調整 | ←→ または右パネル矢印 |
| SHOT開始 | SHOTボタン または Space |
| パワー確定 | Space / Enter |
| 再プレイ（ホールアウト後） | Esc |

## プロジェクト構成

```
scenes/main.tscn      # メインシーン
scripts/
  golf_game.gd        # ゲームロジック・ショット計算
  course.gd           # ホール定義・地形
  clubs.gd            # クラブ性能
  main_view.gd        # 疑似3Dメインビュー
  course_map.gd       # トップダウンマップ
  elevation_graph.gd  # 標高プロファイル
  control_panel.gd    # 操作パネル
  status_bar.gd       # 下部情報バー
  retro_theme.gd      # 共通カラー・パネル描画
```
