# 会話まとめ — フェアウェイ・クロニクル

このドキュメントは、ビッグオナー風ゴルフ＋人生ゲームの企画・実装に関する会話のまとめです。

---

## 最初の質問

**「アートディンク社のビッグオナーのようなゴルフゲーム＋人生ゲームのようなゲームは作れますか？」**

### 結論

**作れます。** 技術的にもゲームデザイン的にも十分現実的です。

| 要素 | 再現・追加のイメージ |
|------|----------------------|
| ビッグオナー風ゴルフ | マルチパネルUI、疑似3Dビュー、クラブ・方向・ショット、風・ライ表示 |
| 人生ゲーム要素 | マス目進行、お金・資産、職業・家族、ランダムイベント、定年ゴール |

### 組み合わせ方（採用方針）

**パターンA：ライフサイクル型** を推奨。

```
幼少期 → 学生（部活・大会）→ 社会人アマ → プロ挑戦 → 引退
         ↑ 各ステージでゴルフラウンド or 人生イベント
```

### 注意点

- **著作権**: 「ビッグオナー」「人生ゲーム」の名称・キャラ・マスデザインの流用は不可。雰囲気と仕組みの参考にとどめる。
- **スコープ**: 最初から両方フル実装しない。「1ホール打てるゴルフ」→「人生イベント1種」の順が現実的。

## 作ったもの

### プロジェクト名

**フェアウェイ・クロニクル**（Fairway Chronicle）

オリジナル作品。ビッグオナー・人生ゲームの名称・キャラ・デザインは使用していない。

### 実装済み機能

| 要素 | 内容 |
|------|------|
| ホール | 第17ホール、600m、目標5回 |
| UI | 地図・疑似3Dビュー・起伏グラフ・操作パネル・案内バー |
| 操作 | 強さ（ゆるく / ふつう / 強く）＋「打つ！」 |
| 補助 | 起動時チュートリアル、平易な日本語、おすすめクラブ自動表示 |

### プロジェクト構成

```
scenes/main.tscn          # メインシーン
scripts/
  golf_game.gd            # ゲームロジック・ショット計算
  course.gd               # ホール定義・地形
  clubs.gd                # クラブ性能
  main_view.gd            # 疑似3Dメインビュー
  course_map.gd           # トップダウンマップ
  elevation_graph.gd      # 起伏プロファイル
  control_panel.gd        # 操作パネル
  status_bar.gd           # 下部情報バー
  help_overlay.gd         # チュートリアル
  retro_theme.gd          # 共通カラー・パネル描画
```

### 起動方法

```bash
godot --path . res://scenes/main.tscn
```

Godot 4.4+ が必要。

## ビギナー向け改善（2回目のフィードバック）

**「ゴルフをやっていないので、もっとわかりやすく簡単に」** という要望に応じて大幅に簡略化。

### 操作の変更

| 以前 | 現在 |
|------|------|
| クラブ選択（1W, 3W…） | 自動おすすめ表示（「遠く飛ばす」等） |
| 方向調整（°表示） | 左 / まっすぐ / 右（そのままでOK） |
| 往復パワーゲージ | ゆるく / ふつう / 強く の3択 |
| SHOT → タイミング確定 | 「打つ！」1回で完了 |

### 用語の平易化

| 以前 | 現在 |
|------|------|
| フェアウェイ | 打ちやすい道 |
| ラフ | 草むら（打ちにくい） |
| バンカー | 砂場 |
| グリーン | カップのある広場 |
| 663Y | ゴールまで 600m |
| club / direction / SHOT | おすすめ / 向き / 打つ！ |

### その他の改善

- 起動時チュートリアル（ルール・操作説明）
- 毎ショット後のヒント表示
- 英語UI・不要ボタン（ADVICE, LAYOUT 等）の削除
- 地図に「スタート」「ゴール」「あなた」ラベル
- 誤差・ペナルティの緩和

### 操作（最短）

1. Godot で起動 → チュートリアルを読んでクリック
2. そのまま **「打つ！」** を押す（「ふつう」「まっすぐ」でOK）
3. 白い旗（ゴール）まで繰り返す

| 操作 | キー / UI |
|------|-----------|
| 強さ変更 | ↑↓ またはボタン |
| 向き変更（任意） | ←→ またはボタン |
| 打つ | 「打つ！」/ Space / Enter |
| 再プレイ | Esc |
