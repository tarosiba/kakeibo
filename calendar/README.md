# 予定カレンダー

月表示・予定の追加・色分けができるシンプルな予定管理アプリです。  
**iPad / iPhone では Safari で開き、「ホーム画面に追加」するとアプリのように使えます。**

## 機能

- 月間カレンダー表示（前月・次月・今日ボタン）
- 日付タップで予定を追加
- 時刻（任意）・6色の色分け
- 予定の削除
- データはブラウザ内（localStorage）に保存
- オフライン対応（Service Worker）

## iPad / iPhone で使う手順

1. `index.html` を **HTTPS** で公開する（GitHub Pages など）
2. **Safari** でページを開く
3. 共有ボタン → **ホーム画面に追加**
4. ホーム画面のアイコンから起動

横向き（ランドスケープ）では、カレンダーと予定パネルが左右に並びます。

## PC で試す

`calendar` フォルダで:

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開く。

## ファイル

- `index.html` … 画面
- `styles.css` … 見た目
- `app.js` … ロジック
- `sw.js` … オフライン用
- `manifest.json` … PWA 用

## 注意

- App Store のネイティブアプリではありません（Webアプリ / PWA）
- iOS のカレンダーアプリとは連携しません
- 機種を変えるとデータは引き継がれません（同じブラウザ内のみ）
- ホーム画面追加は Safari から行ってください（Chrome 等では制限があります）
