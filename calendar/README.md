# 予定カレンダー

月表示・予定の追加・色分けができるシンプルな予定管理アプリです。  
**iPad では Safari で開き、「ホーム画面に追加」するとアプリのように使えます。**

## 機能

- 月間カレンダー表示（前月・次月）
- 日付タップで予定を追加
- 6色から色分け
- 予定の削除
- データはブラウザ内（localStorage）に保存（オフライン可）

## iPad で使う手順

1. `index.html` を Web サーバー経由で開くか、GitHub Pages などに公開する  
   （ファイルを直接開くだけでも動きますが、ホーム画面追加は HTTPS 推奨）
2. Safari でページを開く
3. 共有ボタン → **ホーム画面に追加**
4. ホーム画面のアイコンから起動

## PC で試す

`calendar` フォルダで:

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開く。

## ファイル

- `index.html` … 画面
- `styles.css` … 見た目
- `app.js` … ロジック
- `manifest.json` … PWA 用

## 注意

- App Store のネイティブアプリではありません（Webアプリ / PWA）
- 機種を変えるとデータは引き継がれません（同じブラウザ内のみ）
