# AI Company Proto (Godot 4)

本物の機械学習は使わず、**AI開発会社の経営を数値シミュレーション**する最小プロトタイプです。

## 必要環境

- Godot **4.2** 以上

## 起動

1. `ai-company/project.godot` を Godot で開く
2. **F5** で実行

## 遊び方

| 操作 | 内容 |
|------|------|
| 翌日へ | 1日進める（コスト支払い・開発進行・イベント） |
| 採用 | 研究者 +1（開発速度↑、人件費↑） |
| GPU購入 | GPU +1（開発速度↑、電力費↑） |
| LLM / 画像AI / 推薦AI | 新規プロジェクト開始（同時1件） |
| 中止 | 進行中プロジェクトをキャンセル |

## シミュレーション設計

### 開発フェーズ（架空）

```
データ収集 → 学習 → 評価 → デプロイ → 商用稼働
```

各フェーズは「研究者数 × 8 + GPU数 × 12」の作業量で進みます。

### ローンチ後の品質（乱数 + イベント補正）

- **精度** (accuracy)
- **安全性** (safety) — データ炎上イベントで低下
- **推論速度** (inference_speed)
- **日次収益** — 上記3指標と製品タイプから算出

### ランダムイベント（約22%/日）

- VC資金調達
- 競合の新モデル
- 学習データの偏り指摘
- GPU請求の増加
- 技術ブログで好評
- 学習フェーズの加速

## プロジェクト構成

```
ai-company/
├── project.godot
├── scenes/main.tscn       # UI一式
└── scripts/
    ├── game.gd            # Autoload: 会社状態・日次処理
    ├── ai_project.gd      # 架空AIプロジェクト
    └── main.gd            # UI更新
```
