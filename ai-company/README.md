# AI Company Proto (Godot 4)

本物の機械学習は使わず、**AI開発会社の経営を数値シミュレーション**する最小プロトタイプです。  
LLM製品ローンチ後は、**任意の演出機能**として外部AIチャットデモも利用できます。

## 必要環境

- Godot **4.2** 以上
- （任意）Ollama または OpenAI互換API

## 起動

1. `ai-company/project.godot` を Godot で開く
2. **F5** で実行

## 遊び方

| 操作 | 内容 |
|------|------|
| 翌日へ | 1日進める（コスト支払い・開発進行・イベント） |
| 採用 | 研究者 +1（開発速度↑、人件費↑） |
| GPU購入 | GPU +1（開発速度↑、電力費↑） |
| LLM / 画像AI / 推薦AI | 新規プロジェクト開始（同時1件） |
| 中止 | 進行中プロジェクトをキャンセル |
| 製品デモ | LLMローンチ後にチャット演出を開く（任意） |
| 研究ツリー | 技術研究を開始（費用 + 日数） |
| 安全/均衡/精度 | 学習・評価フェーズ中の開発方針を切替 |
| オート進行 | 1秒=1日で自動進行（モーダル表示中は一時停止） |

## AI市場シェア（競合）

3社の競合AI企業とシェアを奪い合います。

| 競合 | 得意分野 |
|------|----------|
| ApexAI | LLM |
| VisionForge | 画像AI |
| RecoNet | 推薦 |

- **ローンチ**でシェア上昇
- **評判・製品品質**で緩やかにシェア増
- **競合イベント**でシェア低下
- シェアが高いほど **日次収益が増加**（低シェアは収益が伸びにくい）

画面左の「AI市場シェア」パネルで順位と占有率を確認できます。

## オート進行

「オート進行」ボタンで **1秒 = 1日** の自動ターン進行。

- 研究ツリー・製品デモを開いている間は停止
- 資金ショックでゲームオーバー時は自動停止

## 精度 vs 安全性（トレードオフ）

プロジェクトが **学習** または **評価** フェーズの間、開発方針を選べます。

| 方針 | 効果 |
|------|------|
| 安全重視 | 安全性 +14、精度 -8、速度やや低下 |
| 均衡 | 補正なし |
| 精度重視 | 精度 +14、安全性 -10、炎上リスク微増 |

精度重視は学習がやや遅く、安全重視は評価がやや遅くなります。

## 研究ツリー

「研究ツリー」から技術を解禁すると、ローンチ時の品質ボーナスが加算されます。

```
基礎機械学習（初期解禁）
├── Word Embeddings → Transformer → RLHF
├── CNN → Diffusion
└── 協調フィルタリング → バンディット最適化
Transformer + Diffusion → マルチモーダル
```

| 技術 | 主な効果 |
|------|----------|
| Transformer | LLM精度大幅UP |
| Diffusion | 画像AI精度UP |
| RLHF | LLM安全性UP |
| マルチモーダル | 全タイプに小幅ボーナス |

研究は同時に1件のみ。進行は「研究者数 × 6 / 日」です。

## 製品デモチャット（任意・演出）

経営シミュレーション本体とは独立したオプション機能です。

### 安全設計

| 項目 | 実装 |
|------|------|
| APIキー | `user://llm_config.cfg` に保存。ソース直書きなし |
| 環境変数 | `AI_COMPANY_API_KEY` などで上書き可 |
| コスト制限 | 1プレイあたりのリクエスト上限（デフォルト15回） |
| 必須機能にしない | API未設定・障害時はオフライン応答に自動フォールバック |
| レーティング | 全年齢向けモード + 出力フィルタ（不適切語句をマスク） |
| 通信待ち | 応答中は「考え中...」表示、入力ロック |

### 設定手順（Ollama例）

1. [Ollama](https://ollama.com/) をインストールし `ollama pull llama3.2`
2. ゲーム内「製品デモ」→「LLM設定」
3. 「外部AIを有効化」にチェック、プロバイダを Ollama に
4. URL: `http://127.0.0.1:11434/api/chat`

### 環境変数（OpenAI互換API例）

```bash
export AI_COMPANY_PROVIDER=openai
export AI_COMPANY_API_KEY=sk-...
export AI_COMPANY_API_URL=https://api.openai.com/v1/chat/completions
export AI_COMPANY_MODEL=gpt-4o-mini
```

設定例は `config/llm_config.example.ini` を参照（実キーはコミットしないこと）。

## シミュレーション設計

### 開発フェーズ（架空）

```
データ収集 → 学習 → 評価 → デプロイ → 商用稼働
```

各フェーズは「研究者数 × 8 + GPU数 × 12」の作業量で進みます。

### ローンチ後の品質（乱数 + イベント補正）

- **精度** (accuracy)
- **安全性** (safety) — データ炎上イベントで低下
- **推論速度** (inference_speed)
- **日次収益** — 上記3指標と製品タイプから算出

チャットの system プロンプトにも精度・安全性が反映されます。
