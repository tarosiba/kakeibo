# 買い物リスト

品目・数量・カテゴリ付きのシンプルな買い物リストアプリです。  
**iPad では Safari で開き、「ホーム画面に追加」するとアプリのように使えます。**

## 機能

- 品目の追加（数量・カテゴリは任意）
- チェックで購入済みにする
- 未購入 / すべて の表示切り替え
- 購入済みアイテムの一括削除
- データはブラウザ内（localStorage）に保存（オフライン可）

## カテゴリ

- 野菜・果物
- 肉・魚
- 乳製品
- 調味料・乾物
- 日用品
- その他

## PC で試す

`shopping-list` フォルダで:

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開く。

## ファイル

- `index.html` … 画面
- `styles.css` … 見た目
- `app.js` … ロジック
- `manifest.json` … PWA 用

## 注意

- App Store のネイティブアプリではありません（Webアプリ / PWA）
- 機種を変えるとデータは引き継がれません（同じブラウザ内のみ）
