# Stygian Abyss Proto（Ultima Underworld風）

Godot 4 で動く、擬似3Dダンジョン探索アドベンチャーのプロトタイプです。

## 特徴

- **擬似3D迷路** — レイキャスト方式の一人称視点
- **NPC会話** — 亡霊・トロルと会話してクエストを進行
- **オートマップ** — 探索した通路を羊皮紙風マップに表示
- **Ultima Underworld風UI** — 左アクション・右ステータス・下テキストログ

## 必要環境

- Godot Engine 4.2 以上

## 起動方法

1. Godot で `ultima-godot/project.godot` をインポート
2. **F5** で再生

## 操作

| キー | 操作 |
|------|------|
| **W / ↑** | 前進 |
| **S / ↓** | 後退 |
| **A / ←** | 左を向く |
| **D / →** | 右を向く |
| **Q / E** | 左右ストレイフ |
| **T** | 話す（目の前のNPC） |
| **L** | 調べる |
| **Space** | 使う（扉など） |
| **M** | 地図の表示／非表示 |

## クエストの流れ（ヒント）

1. 亡霊に話しかける
2. 東の通路で「古い鍵」を入手
3. 再び亡霊に話しかける
4. 南の鉄の扉（D）を開けてクリア

## 構成

```
ultima-godot/
├── project.godot
├── scenes/game.tscn
└── scripts/
    ├── game.gd          # メインロジック・会話・クエスト
    ├── raycast_view.gd  # 擬似3D描画
    ├── map_canvas.gd    # オートマップ
    └── dungeon_data.gd  # マップデータ
```
